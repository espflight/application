# ESPFlight Application

**Learn. Build. Fly.**

**Official configuration and control application for the ESPFlight platform.**

[Website](https://espflight.com) · [Build v1.0](https://github.com/espflight/docs/blob/main/BUILD_V1.0.md) · [Documentation](https://espflight.com/docs/) · [Firmware](https://github.com/espflight/firmware) · [Hardware Reference](https://github.com/espflight/hardware)

ESPFlight Application provides the user interface for discovering, configuring, monitoring, and controlling compatible drones running ESPFlight Firmware.

The application works together with ESPFlight Firmware to provide a practical interface for setup, telemetry, flight control, and experimentation.

## Features

ESPFlight Application provides:

* Automatic discovery of compatible ESPFlight controllers
* Drone connection and status monitoring
* Live telemetry
* Flight controls
* ARM / DISARM control
* Beginner and Advanced control modes
* Head Lock mode
* PID configuration
* Flight-state monitoring
* Configuration tools
* Support for ESPFlight communication protocols

Available features may depend on the firmware version and hardware configuration.

## Compatibility

ESPFlight Application is designed for use with compatible versions of ESPFlight Firmware.

Firmware and Application communication protocol versions must be compatible.

For the v1.0 release baseline, use ESPFlight Application v1.0.0 with ESPFlight Firmware v1.0.0 and compatible ESPFlight-based hardware.

## Safety

ESPFlight Application can control real motors and flying hardware.

Before flight:

* Verify the connected Drone.
* Verify firmware and hardware configuration.
* Verify control directions.
* Verify ARM / DISARM operation.
* Verify failsafe behavior.
* Keep people, animals, and property clear during testing.

Use ESPFlight responsibly and follow applicable local laws and safety requirements.
